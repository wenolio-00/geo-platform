          关键约束

          真实数据优先

          前端诊断报告流必须走 /api/v1/geo/*，报告数据不得从 fixture 或 demo fallback 生成。

          失败不降级为模拟数据

          模型 API key 缺失、平台请求失败或无完成样本时，run 应进入 failed，并暴露 error 或 message。

          快照是工作台事实源

          报告完成后必须持久化 Dashboard snapshot，后续工作台面板、上期值和历史趋势都应从快照读取。
