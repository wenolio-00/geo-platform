QuerySet 工程落地流程图

从品牌配置到 frozen QuerySet，再到多平台巡检、报告聚合和 Dashboard 历史快照。核心原则是：QuerySet 不是临时 prompt 列表，而是带版本、质量门禁和血缘关系的诊断样本资产。

QuerySet Snapshot 关键字段

身份queryset_id、queryset_version、parent_queryset_id
来源queryset_strategy、queryset_source、matrix_api_request_id
治理policy、change_type、change_reason、approved_by
候选query_candidates 保留 active、archived、rejected 全量审计
生产集queries 只保留 lifecycle_status 为 active 的样本
血缘report_data.lineage 让历史报告可复现、可对比

质量过滤规则

  • QF-01query_text 长度必须在可控范围内。
  • QF-02命中行业禁词时 rejected。
  • QF-03广告化表达归档，不进入生产巡检。
  • QF-04口语场景里出现正式写作标记时归档。
  • QF-05正式场景里出现强情绪表达时归档。
  • QF-06当前批次或同品牌历史 active query 重复时归档。
